# 离线胶片放映编排台

纯离线前端应用（HTML + CSS + 原生 JS，无任何构建与网络依赖），用于管理多间放映室的胶片卷、可替代片段与放映场次。直接双击打开 `index.html`，或在本目录执行 `python3 -m http.server` 后访问均可。

## 功能

- **卷库管理（左栏）**
  - 片段：编号、片长（正整数，分钟）、所属胶片卷、替代组、保存状态、备注；可新增、编辑、删除、搜索。
  - 片段编号全局唯一，**忽略大小写**（`a-001` 与 `A-001` 视为重复）。
  - 同属一个“替代组”的片段互为可替代片段。
  - 胶片卷、放映室可增删（仍被引用时安全拦截）；放映室删除保护取**正式数据引用与当前草稿/未保存场次引用的并集**——草稿把场次从旧厅改到新厅时，旧厅（正式旧引用）与新厅（草稿新引用）都不能删除；未保存场次选中的厅同样受保护；可配置全局默认换卷间隔。
- **场次编排（中栏）**
  - 场次支持新建、复制（同厅、顺延 30 分钟、条目完整克隆并保留替代片段选择）、移除、多标签切换。
  - **复制/新建先停在“未保存”状态**：副本只存在于内存（标签带“未保存”徽标），通过场内校验与跨场冲突检查并手动“保存副本”前**不会进入正式数据、不写本机存档**；刷新、点“还原草稿”、直接移除或切换到其他场次都会丢弃它。放弃副本不进撤销栈；副本保存入档后才作为一步可撤销的有效修改。
  - 每场设定名称、日期、开始时间、放映室、本场换卷间隔。
  - 从片库选片段加入，支持 **拖拽** 或 ↑↓ 按钮换序、移除。
  - 每个条目可在同替代组内切换替代片段（如把原版片头换成修复版片头）。
  - 按开始时间与换卷间隔（相邻两段不同卷时插入）逐段计算起止，支持 **跨午夜**（显示 `+1天`）。
  - 实时显示：正片总时长、换卷缓冲次数/总分钟、占用总时长、开场/散场、跨场冲突。
  - 场次采用“草稿 → 保存”模式：有阻断或跨场冲突时无法保存，可随时还原草稿。
- **核对与阻断（右栏）**
  - **阻断项**：空场次、缺元数据、非法日期/时间、片长非正整数、场内编号重复（忽略大小写）、引用片段缺失、所选放映室已被删除（孤儿厅）等。
  - **冲突**：同一放映室时间重叠；同一胶片卷在不同场次（含跨厅）被同时需要。端点相接不算冲突，换卷缓冲不计入卷占用。
  - **破损风险**（不阻断）：脆化/接片松动/齿孔磨损片段使用、同一卷当日使用次数过多、两场之间休整不足。
  - 每条问题都可**点击定位**：跳到对应场次、在冲突的两场间来回切换、高亮具体片段。
  - 存在任何阻断项或冲突时导出按钮禁用，提示逐项解决。
- **导出**：无阻断/冲突后可导出 UTF-8 文本排期表（每场节目单、逐段起止时间、卷、状态、换卷缓冲、跨午夜标注、破损风险汇总）。
- **撤销/重做**：每次有效修改（增删改卷/片/场、保存、设置等）都可逐步撤销/重做，支持 Ctrl+Z / Ctrl+Y / Ctrl+S，按钮悬停显示最近一步操作名。
- **持久化**：数据与撤销/重做历史都保存在 `localStorage`，刷新/重开浏览器后完整恢复（含撤销栈）；顶部“重置数据”可恢复内置示例。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 三栏布局结构 |
| `styles.css` | 暗色影院主题样式 |

## 运行端到端测试

```bash
cd e2e
npm install
npx playwright install chromium   # 如系统缺库，用包管理器补齐 playwright 提示的共享库
node e2e.js
```

测试走查：复制场次 → 同厅/同卷跨场冲突与定位换厅解决 → 按钮/拖拽换序与实时统计 → 替代片段消除冲突并保存 → 非法时间与跨午夜 → 片长正整数/编号重复校验 → 撤销/重做（快捷键）→ 刷新完整恢复（数据+撤销历史）→ 缺失片段阻断定位 → 阻断时禁用导出与成功导出排期表。

复制门禁专项（第 12 节，独立干净数据）：同厅冲突副本不入 `doc`/存档且强制保存被拒；跨厅同卷冲突仍阻断；复制后刷新副本不残留；改到不冲突时间后正常复制（5 条目、替代关系、时间轴完整）、保存入档并可撤销/重做；"还原"直接丢弃副本且不污染撤销栈；未保存副本期间撤销无关的片库修改不会误杀副本。

放映室引用保护专项（第 13 节）：新建放映室并用于未保存场次时删除被拒（含已保存场次的草稿改厅），被拒操作不进撤销栈；无冲突保存后引用完整；闲置放映室可删除且撤销/重做不影响其他场次引用；刷新后无孤儿厅；外部脏数据造成的孤儿厅会被判为阻断、编辑器下拉提供“请改选”占位、导出禁用，改选有效厅后恢复。

改厅草稿双向保护专项（第 14 节）：草稿把场次从一号厅改到三号厅但不保存时，删除旧厅（正式旧引用）和新厅（草稿新引用）都被拦截，闲置厅不受影响；还原草稿后新厅可删、旧厅仍受保护；保存改厅后旧厅可删、新厅受保护，删旧厅与撤销/重做/刷新全程无孤儿场次；撤销“保存改厅”后场次正式回到旧厅且旧厅重新受保护；时间轴、冲突门禁与导出（含新厅名）按原逻辑工作。
